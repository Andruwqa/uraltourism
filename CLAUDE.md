# Урал — уралтуризм.рф

Сайт «Отдых на Северном Урале». Андрей Пушин — дизайнер, а не разработчик: объясняй по-русски и простыми словами, без жаргона, и перед любым пушем показывай, что меняется. Первую версию сайта в 2022 году залил Alexander Chabin.

## Как устроено

- Статичный сайт: `index.html`, папки `css/`, `js/` (jQuery, flexslider, lightbox), `fonts/`, `images/` (~100 МБ фотографий). Сборки нет.
- Репозиторий: `Andruwqa/uraltourism` (публичный), ветка **`master`**.
- Хостинг: GitHub Pages из `master`, папка `/`. Файл `CNAME` = `xn--80aoclhtcpfe.xn--p1ai` (это уралтуризм.рф в punycode) — не удалять и не писать кириллицей.
- Пуш в `master` = публикация примерно через минуту (большие картинки собираются дольше). В облачной сессии — работать в отдельной ветке и предлагать PR.
- `_config.yml` исключает `CLAUDE.md` и `README.md` из публикации на сайте. Не удалять; новые служебные файлы добавлять туда же.
- На Mac: локальная копия в `~/Documents/Sites/uraltourism`, доступ к GitHub по SSH (аккаунт Andruwqa), утилиты `gh` нет, реестр npm в рабочей сети заблокирован.

## Домены

- **уралтуризм.рф** — основной адрес сайта.
- **rest-urals.ru** — только перенаправляет на уралтуризм.рф. Перенаправление живёт в отдельном репозитории `Andruwqa/rest-urals-redirect` (на Mac: `~/Documents/Sites/rest-urals-redirect`): `index.html` и `404.html` с переходом на тот же путь на новом домене, `CNAME` = `rest-urals.ru`.
- Регистратор обоих: ATEX (my.atex.ru), DNS-хостинг тоже у ATEX (`ns1.dnseven.com`, `ns2.dnseven.net`).
- Записи у обоих доменов: `@` → A 185.199.108.153 / .109.153 / .110.153 / .111.153; `www` → CNAME `andruwqa.github.io.`
- Оба домена оплачены до 15.06.2027.
